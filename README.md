# Glod an Ere

An economy and road-building strategy game for tablet and PC, made with Godot 4.

Lead your people from the Neolithic through the Copper and Bronze Age into the Iron Age:
lay paths between flags, let carriers move goods, and grow production chains era by era.

## Run
Open the folder in Godot 4.3 and press Play.

## Tests
```
godot --headless --path . -s tests/sim_test.gd
```
